⚙ Configure seu Client ID do Google
Para salvar no Google Drive, você precisa de um Client ID gratuito do Google. É feito uma única vez e leva uns 5 minutos.
1Acesse console.cloud.google.com e crie um projeto (pode ser qualquer nome)
2Vá em APIs e Serviços → Credenciais → Criar Credenciais → ID do cliente OAuth 2.0
3Escolha tipo Aplicativo da Web. Em "Origens JS autorizadas" adicione null e também o caminho local do arquivo (ex: file://)
4Ative a Google Drive API em APIs e Serviços → Biblioteca
5Cole o Client ID abaixo e clique em Salvar
O Client ID fica salvo no seu arquivo HTML, não sai da sua máquina.
